# pacmd

This work aims to replicate Hone, Rossky and Voth's work on benchmarking PACMD, RPMD for quartic oscillator: Tyler D. Hone; Peter J. Rossky; Gregory A. Voth, A comparative study of imaginary time path integral based methods for quantum dynamics, J. Chem. Phys. 124, 154103 (2006). https://doi.org/10.1063/1.2186636
